# 마일스톤 7a: 배속·일시정지·키 설정·게임패드 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:**
- 배속(누르는 동안, 2×/4×/무제한)과 일시정지(토글)를 넣는다.
- 키보드·게임패드 매핑을 설정 창에서 바꾸고 `config.toml`에 저장한다.
- gilrs로 게임패드를 자동 인식한다.

**Architecture:**
- `aragorn-app`:
  - `pacing`에 `FastForward`(2×/4×/무제한, 기본 4×), `RunMode`(일시정지/보통/배속), `SpeedControl`(일시정지 토글)을 더한다.
  - `FramePacer::frames_scaled(elapsed, multiplier)`는 상한도 배율만큼 늘린다. `reset()`은 남은 시간을 버린다.
  - `Session::run(elapsed, mode, keep_going)`이 모드별로 프레임을 돌린다.
    - 일시정지는 0프레임이고 남은 시간도 버린다.
    - 2×와 4×는 경과 시간의 배수만큼 돌린다.
    - 무제한은 `keep_going`이 참인 동안 돌린다(최소 1, 최대 `UNLIMITED_MAX_FRAMES` 120).
    - 보통 속도가 아니면 다음 `pump_audio`가 소리를 버린다.
  - 새 `input` 모듈:
    - `Action`(버튼 8개 + 배속 + 일시정지)과 `Bindings`(기능마다 키 이름 문자열, 빈 문자열은 지정 안 함)를 둔다.
    - `bind`는 같은 이름을 쓰던 다른 기능의 지정을 해제한다.
    - `InputConfig { keyboard, gamepad, fast_forward }`는 항목이 빠지거나 배속 값을 모르면 그 항목만 기본값을 쓴다.
    - `Config`에 `input`을 더한다.
- `aragorn-desktop`:
  - `ui::input`:
    - `Keymap`이 키 이름을 egui `Key`로 바꾼다. 모르는 이름이면 기본 키를 쓴다.
    - `gather`가 키보드와 패드(`PadInput`)를 OR로 합쳐 `InputFrame`을 만든다.
  - `ui::settings::SettingsView`:
    - 설정 창이다. 칸을 누르면 다음 키나 패드 버튼을 지정하고, 오른쪽 클릭하면 해제한다.
    - 배속 속도를 고르는 라디오 버튼과 "기본값으로" 버튼이 있다.
    - 입력을 기다리는 동안 게임에는 버튼을 모두 뗀 상태를 넘긴다.
  - `adapters::Gamepads`(gilrs):
    - 연결과 해제를 알린다.
    - 매핑된 버튼과 왼쪽 스틱(데드존 0.5, 방향 고정)을 `PadInput`으로 바꾼다.
    - gilrs를 쓸 수 없으면 키보드만으로 돈다.
  - `app.rs`: 툴바에 "설정" 버튼이 있고, 상태 표시줄에 "일시정지"·"배속 (4배)"를 보인다. 무제한 배속은 화면 갱신마다 `UNLIMITED_BUDGET`(12ms)까지 돈다.

**Tech Stack:** Rust 1.99 (edition 2024), 새 의존성 `gilrs 0.11`(데스크톱만). 리눅스 빌드에 `libudev-dev`가 필요하다.

**Spec:** `docs/superpowers/specs/2026-10-07-gameboy-emulator-design.md` (§5.1 속도 제어, §5.2 설정, §6.2 입력, §9의 마일스톤 7)

## 스펙과 다른 결정 (리뷰어 확인용)

1. **무제한 배속은 시간 예산으로 돈다.** 화면 갱신마다 12ms까지, 최대 120프레임이다. 스펙(§5.1)은 "무제한"이라고만 한다. UI와 입력이 멈추지 않게 하려는 것이다.
2. **일시정지 중에도 소리를 버린다.** 배속처럼 일시정지 앞뒤로 쌓인 시간도 버려서, 풀었을 때 몰아서 돌지 않는다.
3. **키 이름은 문자열로 저장한다.** 키보드는 egui `Key::name()`, 패드는 gilrs `Button` 변형 이름이다. 빈 문자열은 "지정 안 함"이다. 앱 계층이 egui나 gilrs에 기대지 않게 하려는 것이다.
4. **게임패드 기본값에서 배속은 RightTrigger(R1)이고 일시정지는 지정하지 않는다.** 스펙에 없는 부분이다. 많은 게임이 Start를 메뉴로 쓰고, Mode(가이드) 버튼은 OS가 가로채는 경우가 있다.
5. **왼쪽 스틱은 방향 버튼에 고정한다**(데드존 0.5). 설정 창에서 바꾸지 않는다.
6. **F1–F10 스테이트 단축키는 M7b에서 넣는다.**

## Review Focus

1. **일시정지·배속 전환**: 풀었을 때 프레임이 몰리거나 소리 지연이 쌓이지 않아야 한다. → `paused_runs_nothing_and_forgets_elapsed_time`, `fast_forward_and_pause_mute_audio_until_normal_speed`
2. **설정 파일이 일부만 있거나 값이 틀린 경우**: 그 항목만 기본값을 쓰고 나머지는 지킨다. 모르는 키 이름은 기본 키, 모르는 배속 값은 4×를 쓴다. → `missing_entries_fall_back_to_their_own_defaults`, `unknown_fast_forward_falls_back_to_default`, `partial_input_section_keeps_other_bindings`, `unknown_name_falls_back_to_default_and_empty_unbinds`
3. **키 충돌**: 한 키를 두 기능에 지정하면 앞의 지정이 풀린다. Escape를 다른 기능에 지정하면 일시정지에서 빠진다. → `binding_a_used_key_unbinds_the_old_action`, `escape_can_be_bound_like_any_key`
4. **무제한 배속이 UI를 붙잡지 않는지**: 예산과 상한이 있어야 한다. → `unlimited_runs_while_budget_lasts`
5. **게임패드가 없거나 빠질 때**: gilrs 초기화가 실패하면 키보드만으로 돈다. 버튼을 누른 채 패드를 뽑아도 버튼이 눌린 채로 남지 않아야 한다(연결된 패드만 훑는다).
6. **설정 창에서 키를 받는 프레임**: 그 키가 게임 입력이나 일시정지로 새지 않아야 한다(`gather_input`이 `None`을 돌려준다).
