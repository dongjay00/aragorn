# 마일스톤 6b: MBC3 실시간 시계(RTC) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 금·은·크리스탈의 게임 안 시계를 움직인다.
- MBC3 RTC 레지스터와 래치를 구현한다.
- 시계 값을 `.sav` 뒤 48바이트 RTC 블록으로 저장한다(BGB/VBA-M 형식).
- 앱을 다시 켜면 꺼져 있던 시간만큼 시계를 진행한다.

**Architecture:**
- `gb-core`:
  - 새 `rtc` 모듈(`Rtc`, `RtcRegs`)이 초·분·시·일(9비트)·정지·넘침, 래치(0→1), 저장 블록 읽기·쓰기, 꺼져 있던 시간 반영을 맡는다.
  - 시계는 에뮬레이션 시간(4194304 dot = 1초)으로 간다. 배속하면 게임 시간도 빨라진다(스펙 §4.7). CGB 2배속에서도 dot 기준이라 실제 속도와 같다.
  - `Cartridge`는 MBC3+TIMER(0x0F, 0x10)에 `Rtc`를 둔다. 0xA000–0xBFFF에서 RTC 레지스터를, 0x6000–0x7FFF 쓰기로 래치를 처리한다.
  - `GameBoy::battery_ram(now_unix)`는 RAM 뒤에 RTC 블록을 붙인다. `load_battery_ram(data, now_unix)`는 블록을 읽고 지난 시간을 반영한다. `GameBoy::cartridge_ram_len()`을 추가한다.
  - 버스는 M-사이클마다 카트리지에 dot을 넘긴다.
- `aragorn-app`:
  - 포트 `Clock { now_unix }`(스펙 §3.3)를 둔다.
  - `Session::load(rom, store, clock)`은 불러올 때와 저장할 때마다 현재 시각을 쓴다.
  - 짧은 세이브 경고는 RAM 크기를 기준으로 한다. RTC 블록이 없는 이전 세이브는 정상으로 본다.
- `aragorn-desktop`: `SystemClock` 어댑터를 둔다. `load_session(path)`가 시스템 시계를 넘긴다.

**Tech Stack:** Rust 1.99 (edition 2024), 새 의존성 없음

**Spec:** `docs/superpowers/specs/2026-10-07-gameboy-emulator-design.md` (§3.3 포트 `Clock`, §4.1 `battery_ram`/`load_battery_ram`, §4.6 MBC3, §4.7 RTC, §4.8 세이브 형식, §5.1 세션, §9의 마일스톤 6)

## 스펙과 다른 결정 (리뷰어 확인용)

1. **`GameBoy::battery_ram(&self, now_unix: u64)`로 인자를 더한다.** 스펙 §4.1의 `battery_ram(&self)`는 RTC 블록의 저장 시각을 넣을 방법이 없다. 코어는 실제 시간을 모르므로(§4.2) 앱이 `Clock`으로 넘긴다.
2. **`Session::load`는 `now_unix` 대신 `Box<dyn Clock>`를 받는다.** 저장할 때마다 현재 시각이 필요해서다. 스펙 §3.3 포트 목록과 §5.1의 "Clock 시각과 함께 코어에 주입"을 따른 모양이다.
3. **앱을 끌 때 RTC 때문에 따로 저장하지 않는다.**
   - 세이브는 지금처럼 게임이 RAM에 쓸 때만 한다.
   - 다음에 켤 때 "마지막 저장의 레지스터 + (지금 − 저장 시각)"으로 계산하므로, 저장 뒤 시계가 흐른 만큼은 그대로 반영된다.
   - 게임 안에서 시계를 바꾸면 RTC 쓰기도 저장 대상(dirty)이 된다.
4. **시계가 뒤로 간 경우(저장 시각이 미래)는 진행하지 않는다.** 날짜가 511일을 넘으면 일 카운터를 감싸고 넘침 비트를 켠다. 게임이 "시계 리셋"을 알린다.

## Review Focus

1. **이전 세이브(RTC 블록 없음)**: M5까지 만든 금·은·크리스탈 세이브를 읽을 때 오류나 경고 없이 RAM이 그대로 실리고, 시계는 0부터 간다. → `save_without_rtc_block_starts_clock_from_zero`, `save_without_rtc_block_is_not_reported_short`
2. **깨진 RTC 블록(길이가 44·48이 아니거나 값이 범위 밖)**: 패닉 없이 무시하거나 하드웨어처럼 감싸야 한다. → `wrong_length_block_is_ignored`, `out_of_range_seconds_wrap_without_carry`
3. **오래 꺼 둔 경우(수년)와 시계가 뒤로 간 경우**: 넘침 비트를 켜고, 음수 경과는 0으로 본다. → `offline_time_past_day_511_sets_carry`, `clock_going_backwards_does_not_advance`
4. **RTC가 없는 MBC3(0x13 등)와 다른 MBC**: 지금과 같아야 한다. 세이브 길이도 바뀌지 않는다. → `only_battery_types_expose_battery_ram`, `mbc3_selects_7bit_rom_bank_ram_banks_and_hides_rtc`
5. **2배속에서 시계 속도**: dot 기준이라 실제 시간과 같아야 한다. → `Rtc::tick(dots)`, 버스가 `dots`를 넘기는지 (`cartridge_rtc_runs_on_emulated_time`)

+/// 세이브 파일 뒤에 붙는 RTC 블록 길이 (BGB/VBA-M 형식, 타임스탬프 u64).

+/// DH 비트: 일 카운터 비트 8, 정지, 일 카운터 넘침.
+const DH_DAY_HIGH: u8 = 0x01;
+const DH_HALT: u8 = 0x40;
+const DH_CARRY: u8 = 0x80;
+
+/// RTC 레지스터 5개 (S, M, H, DL, DH).
+#[derive(Debug, Clone, Copy, Default, PartialEq, Eq)]
+pub struct RtcRegs {
+    pub seconds: u8,
+    pub minutes: u8,
+    pub hours: u8,
+    pub day_low: u8,
+    pub day_high: u8,
+}
+
+impl RtcRegs {
+    /// `select`(0x08–0x0C)가 가리키는 레지스터. 쓰지 않는 비트는 0으로 읽힌다.
+    fn get(&self, select: u8) -> u8 {
+        match select {
+            0x08 => self.seconds & 0x3F,
+            0x09 => self.minutes & 0x3F,
+            0x0A => self.hours & 0x1F,
+            0x0B => self.day_low,
+            _ => self.day_high & (DH_DAY_HIGH | DH_HALT | DH_CARRY),
+        }
+    }
+
+    fn day(&self) -> u16 {
+        u16::from(self.day_high & DH_DAY_HIGH) << 8 | u16::from(self.day_low)
+    }
+
+    fn set_day(&mut self, day: u16) {
+        self.day_low = day as u8;
+        self.day_high = (self.day_high & !DH_DAY_HIGH) | ((day >> 8) as u8 & DH_DAY_HIGH);
+    }
+
+    /// 1초 진행한다. 범위를 벗어난 값(게임이 직접 쓴 60초 등)은 6비트에서 감싸고 올림하지 않는다.
+    fn tick_second(&mut self) {
+        self.seconds = (self.seconds + 1) & 0x3F;
+        if self.seconds != 60 {
+            return;
+        }
+        self.seconds = 0;
+        self.minutes = (self.minutes + 1) & 0x3F;
+        if self.minutes != 60 {
+            return;
+        }
+        self.minutes = 0;
+        self.hours = (self.hours + 1) & 0x1F;
+        if self.hours != 24 {
+            return;
+        }
+        self.hours = 0;
+        self.advance_days(1);
+    }
+
+    /// 일 카운터를 `days`만큼 올린다. 511을 넘으면 감싸고 넘침 비트를 켠다.
+    fn advance_days(&mut self, days: u64) {
+        let total = u64::from(self.day()) + days;
+        if total > 511 {
+            self.day_high |= DH_CARRY;
+        }
+        self.set_day((total % 512) as u16);
+    }
+
+    /// `seconds`초 진행한다. 레지스터가 정상 범위면 한 번에 계산한다.
+    fn advance(&mut self, seconds: u64) {
+        if self.seconds >= 60 || self.minutes >= 60 || self.hours >= 24 {
+            // 비정상 값은 1초씩 진행해 하드웨어와 같은 감싸기를 따르되, 한 바퀴(1일) 안에서 정상 범위로 돌아온다.
+            let mut left = seconds;
+            while left > 0 && (self.seconds >= 60 || self.minutes >= 60 || self.hours >= 24) {
+                self.tick_second();
+                left -= 1;
+            }
+            if left > 0 {
+                self.advance(left);
+            }
+            return;
