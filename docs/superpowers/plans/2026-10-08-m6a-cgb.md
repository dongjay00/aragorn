# 마일스톤 6a: GBC 하드웨어 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CGB 플래그가 있는 ROM(노랑, 금, 은, 크리스탈)을 GBC 모드로 실행한다. 화면은 컬러로 나오고 소리는 GBC 동작을 따른다. `cgb-acid2`와 Blargg `cgb_sound` 12개를 통과한다. 레드·블루 같은 DMG ROM은 지금처럼 DMG로 돈다.

**Architecture:**
- `gb-core`:
  - `Model`을 `Bus`까지 넘기고, `Ppu`와 `Apu`는 `cgb` 플래그로 동작을 나눈다.
  - PPU:
    - VRAM 뱅크 2개(VBK), BG·스프라이트 팔레트 RAM(BCPS/BCPD, OCPS/OCPD)
    - BG 타일 속성(팔레트, 뱅크, 반전, 우선순위), CGB 스프라이트 우선순위(OAM 순서), LCDC 비트 0의 CGB 의미
    - 2-dot 단위 진행, HBlank 시작 신호
  - 버스:
    - WRAM 뱅크 8개(SVBK), KEY1과 STOP으로 2배속 전환
    - HDMA(범용, HBlank), OPRI
    - dot 카운터: 2배속에서도 한 프레임은 70224 dot이다.
  - APU:
    - CGB 웨이브 RAM 규칙: 언제나 접근할 수 있고, 다시 트리거해도 손상되지 않는다.
    - 전원을 끄면 길이 카운터를 지운다.
    - PCM12/PCM34를 추가한다.
    - 믹서는 T-사이클 가중 평균을 쓴다(2배속 M-사이클은 2 T-사이클).
- `aragorn-app`: `Session`이 `Model::Auto`로 헤더의 CGB 플래그를 따른다. M3에서 붙인 "모두 DMG로" 임시 조치를 없앤다.
- `aragorn-desktop`: 바뀌는 것이 없다. 프레임버퍼가 이미 RGBA다.

**Tech Stack:** Rust 1.99 (edition 2024), 새 의존성 없음

**Spec:** `docs/superpowers/specs/2026-10-07-gameboy-emulator-design.md` (§4.3 실행 모델, §4.4 PPU CGB, §4.5 APU, §4.6 모델 자동 선택, §8 테스트, §9의 마일스톤 6)

## 스펙과 다른 결정 (리뷰어 확인용)

1. **DMG ROM은 DMG로 돈다.**
   - GBC가 DMG 게임에 입히는 호환 팔레트(컬러화)는 하지 않는다. 스펙 §4.6대로 CGB 플래그가 없으면 DMG다.
   - mooneye의 `misc/*-C`, `*-cgb` 테스트는 CGB 플래그가 없는 ROM을 GBC 하드웨어에서 돌리는 호환 모드용이라 넣지 않는다. 다섯 개 모두 플래그 0x00이다.
2. **CGB 세부 동작 중 넣지 않는 것:**
   - 속도 전환 때 CPU가 약 2050 M-사이클 멈추는 동작
   - STOP 저전력 모드
   - 모드 3 동안 VRAM·팔레트 접근 차단
   - HBlank DMA 중 CPU 정지

   범용 DMA는 16바이트마다 8(2배속은 16) M-사이클 멈춘다. 게임이 눈에 띄게 달라지면 다음 패치에서 넣는다.
3. **색 보정은 하지 않는다.** 5비트 채널을 `(c << 3) | (c >> 2)`로 늘린다. cgb-acid2 기준 이미지와 같은 변환이다. 스펙 §4.4에서 LCD 색감 보정은 옵션이다(설정 화면 M7).
4. **RTC는 M6b다.** 금·은·크리스탈은 지금도 시작하고 플레이할 수 있다. 다만 MBC3 RTC 레지스터가 0xFF로 읽혀서 게임 안 시계가 흐르지 않는다.
5. **OPRI(FF6C)는 값만 저장한다.** CGB 모드 스프라이트는 언제나 OAM 순서로 우선한다.

## Review Focus

1. **DMG ROM이 그대로인지(레드·블루)**: CGB 분기가 DMG 경로를 바꾸지 않아야 한다. → 기존 DMG 인수 테스트 전체(dmg-acid2, Blargg, dmg_sound, mooneye 77)와 `dmg_has_no_vram_bank_or_color_palettes`, `dmg_ignores_cgb_registers`
2. **2배속에서 프레임 길이와 소리 높이**: 화면은 59.7fps, 소리는 같은 높이여야 한다. → `frames_keep_their_length_in_double_speed`, `double_speed_ticks_keep_pitch`, `half_length_pushes_produce_the_same_rate`
3. **HDMA 경계**:
   - 길이 0x7F(2KB) 범용 전송에서 도착지가 VRAM 끝을 넘으면 0x1FFF에서 감싼다.
   - HBlank 전송을 멈추거나 다시 시작해도 패닉하지 않아야 한다.
   → `hblank_hdma_can_be_cancelled`, `hdma_block`의 `& 0x1FFF`
4. **배터리 세이브**: CGB 게임(MBC3/MBC5)도 기존 `.sav` 경로를 그대로 쓴다. → 바뀐 코드 없음. 카트리지 테스트가 그대로 통과한다.
5. **ROM 교체(DMG ↔ CGB)**: 세션마다 `GameBoy`를 새로 만들므로 모델이 섞이지 않는다. → `model_follows_cgb_flag`
